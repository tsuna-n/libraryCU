# Rust E0432 - Unresolved import

E0432 means Rust could not resolve an imported path. For an external crate, compare the first path segment with dependencies in `Cargo.toml`. For a local module, verify its declaration, visibility, and path.

Add a genuinely missing dependency with `cargo add <crate>`, then verify with `cargo check`.
