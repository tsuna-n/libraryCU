# Rust E0432 - Unresolved import

E0432 เกิดขึ้นเมื่อ Rust ไม่สามารถหา module, crate หรือ item ตาม path ที่ระบุในคำสั่ง `use` ได้

## ก่อนแก้ (Before - Error)
```rust
use serde::Serialize; // ERROR: unresolved import `serde`
```
*(เกิดจากยังไม่ได้เพิ่ม `serde` ใน `Cargo.toml` หรือชื่อ path สะกดผิด)*

## แก้แล้ว (After - Success)
```bash
# เพิ่ม dependency ลงใน Cargo.toml
$ cargo add serde --features derive
```
```rust
use serde::Serialize; // SUCCESS: หา crate พบและ compile ผ่าน
```

## การทำงาน (How it works)
- หากเป็น crate ภายนอก: ตรวจสอบว่าได้เพิ่มลงใน `[dependencies]` ใน `Cargo.toml` หรือยัง (แนะนำใช้ `cargo add <crate>`)
- หากเป็น local module: ตรวจสอบว่าประกาศ `mod <name>;` ไว้ใน root (`main.rs`/`lib.rs`) หรือยัง และกำหนด visibility เป็น `pub` หรือไม่
- ตรวจสอบความถูกต้องด้วย `cargo check`
