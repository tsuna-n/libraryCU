# Rust E0432 - Unresolved import

## Quick answer

E0432 means Rust cannot find the crate, module, or item named in a `use` path. Check the spelling and visibility; for an external crate, add the dependency and required features to `Cargo.toml`.

## Example

```bash
$ cargo add serde --features derive
```

```rust
use serde::Serialize;
```

## Verify

Run `cargo check` and confirm that E0432 no longer appears.

# Rust E0432 - ไม่พบ import

## คำตอบสั้น ๆ

E0432 หมายถึง Rust หา crate, module หรือ item ในคำสั่ง `use` ไม่พบ ให้ตรวจการสะกดและ visibility หากเป็น crate ภายนอกให้เพิ่ม dependency และ features ที่จำเป็นใน `Cargo.toml`

## ตัวอย่าง

```bash
$ cargo add serde --features derive
```

```rust
use serde::Serialize;
```

## ตรวจสอบผล

รัน `cargo check` และตรวจว่าไม่มี E0432 เหลืออยู่
