# Rust E0382 - Use of moved value

## Quick answer

E0382 occurs when code uses a non-`Copy` value after its ownership moved elsewhere. Prefer borrowing when the receiver only needs to read the value, or clone it when an independent owned copy is required.

## Example

```rust
let name = String::from("Alice");
let other = &name;
println!("{name} has {} bytes", other.len());
```

## Verify

Run `cargo check` and confirm that E0382 no longer appears.

# Rust E0382 - ใช้ค่าหลังย้าย ownership

## คำตอบสั้น ๆ

E0382 เกิดเมื่อโค้ดนำค่าชนิดที่ไม่ใช่ `Copy` ไปใช้อีกครั้ง หลัง ownership ถูกย้ายไปแล้ว ถ้าผู้รับต้องการเพียงอ่านให้ส่ง reference หรือใช้ `.clone()` เมื่อต้องการสำเนาที่เป็นเจ้าของแยกกันจริง ๆ

## ตัวอย่าง

```rust
let name = String::from("Alice");
let other = &name;
println!("{name} has {} bytes", other.len());
```

## ตรวจสอบผล

รัน `cargo check` และตรวจว่าไม่มี E0382 เหลืออยู่
