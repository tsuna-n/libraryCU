# Rust E0382 - Use of moved value

E0382 occurs when code uses a value after ownership has moved elsewhere. Types such as `String` do not implement `Copy`.

Prefer borrowing when the callee only needs to read the value. Cloning is appropriate only when a distinct owned value is required. Verify a fix with `cargo check`.
