# Rust E0382 - Use of moved value

E0382 occurs when code uses a value after ownership has moved elsewhere. Types such as `String` do not implement `Copy`.

## ก่อนแก้ (Before - Error)
```rust
let name = String::from("Alice");
let other = name; // ownership ถูกย้าย (move) ไปยัง other
println!("{name}"); // ERROR: borrow of moved value: `name`
```

## แก้แล้ว (After - Success)
```rust
let name = String::from("Alice");
let other = &name; // เปลี่ยนมาใช้ borrow (&) แทนการย้าย ownership
println!("{name}"); // SUCCESS: name ยังสามารถใช้งานต่อได้
```

## การทำงาน (How it works)
- Prefer borrowing when the callee only needs to read the value.
- ข้อมูล Heap จะถูก Move เพื่อป้องกัน Double Free หากต้องการเพียงแค่อ่านค่าให้ใช้ Reference (`&name`)
- หากจำเป็นต้องมีสำเนาข้อมูลอิสระอีกชุด ให้ใช้ `.clone()`
- ตรวจสอบความถูกต้องด้วย `cargo check`
