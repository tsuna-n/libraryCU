# Rust E0308 - Mismatched types

## Quick answer

E0308 means an expression has a different type from what Rust expects. Read the `expected ... found ...` pair, then convert the value with an appropriate method such as `.to_string()`, or change the function signature so both sides agree.

## Example

```rust
fn greet(name: String) {}

let name: &str = "Alice";
greet(name.to_string()); // Convert &str to String.
```

## Verify

Run `cargo check` and confirm that E0308 no longer appears.

# Rust E0308 - ชนิดข้อมูลไม่ตรงกัน

## คำตอบสั้น ๆ

E0308 หมายถึงชนิดข้อมูลของค่าที่ส่งเข้าไปไม่ตรงกับชนิดที่ Rust ต้องการ ให้อ่านคู่ `expected ... found ...` แล้วแปลงค่าด้วยวิธีที่เหมาะสม เช่น `.to_string()` หรือแก้ชนิดในฟังก์ชันให้ตรงกัน

## ตัวอย่าง

```rust
fn greet(name: String) {}

let name: &str = "Alice";
greet(name.to_string()); // แปลง &str เป็น String
```

## ตรวจสอบผล

รัน `cargo check` และตรวจว่าไม่มี E0308 เหลืออยู่
