# Rust E0308 - Mismatched types

E0308 occurs when an expression has a type different from the expected type, for example passing `&str` where `String` is expected or mixing integer types.

Read the `expected ... found ...` pair in the diagnostic: it names both sides of the mismatch. Convert the value explicitly (`to_string()`, `to_owned()`, `parse()`, `as` casts) or change the signature so both sides agree. Verify with `cargo check`.
