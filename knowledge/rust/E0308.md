# Rust E0308 - Mismatched types

E0308 occurs when an expression has a type different from the expected type. สังเกตคู่ `expected ... found ...` ในข้อความ diagnostic แล้วแปลงค่า เช่น ใช้ `to_string()` หรือเปลี่ยน function signature ให้ตรงกัน

## ก่อนแก้ (Before - Error)
```rust
fn greet(name: String) {}

let name: &str = "Alice";
greet(name); // ERROR: expected struct `String`, found `&str`
```

## แก้แล้ว (After - Success)
```rust
fn greet(name: String) {}

let name: &str = "Alice";
greet(name.to_string()); // SUCCESS: แปลง &str เป็น String ด้วย .to_string()
```

## การทำงาน (How it works)
- อ่านข้อความ `expected ... found ...` เพื่อตรวจดูชนิดข้อมูลทั้งสองฝั่ง
- แปลงชนิดข้อมูลให้ตรงกัน เช่น `.to_string()`, `.to_owned()`, หรือ `as` cast
- ตรวจสอบความถูกต้องด้วย `cargo check`
