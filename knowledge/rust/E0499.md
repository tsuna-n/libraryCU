# Rust E0499 - Multiple mutable borrows

E0499 เกิดขึ้นเมื่อมีการสร้าง mutable borrow (`&mut`) ซ้ำซ้อนกับตัวแปรเดียวกันในช่วงเวลา (lifetime) ที่ซ้อนทับกัน

## ก่อนแก้ (Before - Error)
```rust
let mut list = vec![1, 2, 3];

let first = &mut list;
let second = &mut list; // ERROR: cannot borrow `list` as mutable more than once at a time

first.push(4);
second.push(5);
```

## แก้แล้ว (After - Success)
```rust
let mut list = vec![1, 2, 3];

// ใช้งาน borrow แรกให้เสร็จก่อน
list.push(4);

// จากนั้นจึงทำ mutable borrow ถัดไป
list.push(5);
// SUCCESS: ไม่มีการทับซ้อนของ mutable borrow
```

## การทำงาน (How it works)
- กฎ Exclusive Reference ของ Rust ห้ามไม่ให้มี `&mut` มากกว่า 1 ตัวพร้อมกัน เพื่อป้องกัน Data Race
- **ทางแก้**: ย่ออายุ (lifetime) ของ mutable reference ตัวแรกให้สิ้นสุดก่อนเริ่มตัวถัดไป
- หากเป็น struct ที่มีหลาย fields สามารถ borrow แยกฟิลด์อิสระออกจากกันได้
- ตรวจสอบความถูกต้องด้วย `cargo check`
