# Rust E0499 - Multiple mutable borrows

E0499 occurs when mutable borrows of the same value overlap. Rust permits many immutable references or one mutable reference at a time.

Shorten the first borrow's lifetime, split disjoint fields, or restructure the operation. Verify with `cargo check`.
