# Rust E0499 - Multiple mutable borrows

## Quick answer

E0499 occurs when mutable borrows of the same value overlap. Finish using the first `&mut` reference before creating another, or borrow independent struct fields separately.

## Example

```rust
let mut list = vec![1, 2, 3];
list.push(4);
list.push(5);
```

## Verify

Run `cargo check` and confirm that E0499 no longer appears.

# Rust E0499 - ยืมแบบ mutable ซ้ำกัน

## คำตอบสั้น ๆ

E0499 เกิดเมื่อ mutable borrow ของค่าเดียวกันมีช่วงเวลาซ้อนกัน ให้ใช้ reference แบบ `&mut` ตัวแรกให้เสร็จก่อนสร้างตัวถัดไป หรือแยกยืมคนละ field ของ struct

## ตัวอย่าง

```rust
let mut list = vec![1, 2, 3];
list.push(4);
list.push(5);
```

## ตรวจสอบผล

รัน `cargo check` และตรวจว่าไม่มี E0499 เหลืออยู่
