# Rust E0433 - Failed to resolve a crate or module

E0433 เกิดขึ้นเมื่อเรียกใช้งาน crate หรือ module โดยตรงผ่าน inline path แต่ compiler ไม่รู้จัก path หรือ identifier นั้น

## ก่อนแก้ (Before - Error)
```rust
fn main() {
    let _ = serde_json::json!({ "status": "ok" });
    // ERROR: failed to resolve: use of undeclared crate or module `serde_json`
}
```

## แก้แล้ว (After - Success)
```bash
# เพิ่ม crate ลงในโปรเจกต์
$ cargo add serde_json
```
```rust
fn main() {
    let _ = serde_json::json!({ "status": "ok" });
    // SUCCESS: ใช้งาน macro ของ serde_json ได้ถูกต้อง
}
```

## การทำงาน (How it works)
- ตรวจสอบการสะกดชื่อ crate หรือ module path ให้ถูกต้อง
- สำหรับ crate ภายนอก ตรวจสอบการประกาศ dependency และ features ที่จำเป็นใน `Cargo.toml`
- สำหรับ module ภายใน ตรวจสอบว่าโมดูลนั้นถูกประกาศเป็น `pub mod` แล้วหรือยัง
- ตรวจสอบความถูกต้องด้วย `cargo check`
