# Rust E0433 - Failed to resolve a crate or module

## Quick answer

E0433 means a crate or module path cannot be resolved. Check the path spelling and module declaration; for an external crate, add it to `Cargo.toml` with any required features.

## Example

```bash
$ cargo add serde_json
```

```rust
fn main() {
    let _ = serde_json::json!({ "status": "ok" });
}
```

## Verify

Run `cargo check` and confirm that E0433 no longer appears.

# Rust E0433 - หา crate หรือ module ไม่พบ

## คำตอบสั้น ๆ

E0433 หมายถึง Rust หา crate หรือ module ตาม path ที่ระบุไม่พบ ให้ตรวจการสะกดและการประกาศ module หากเป็น crate ภายนอกให้เพิ่ม dependency พร้อม features ที่จำเป็นใน `Cargo.toml`

## ตัวอย่าง

```bash
$ cargo add serde_json
```

```rust
fn main() {
    let _ = serde_json::json!({ "status": "ok" });
}
```

## ตรวจสอบผล

รัน `cargo check` และตรวจว่าไม่มี E0433 เหลืออยู่
